# Personal site

Plain static HTML for GitHub Pages (`xChocapic.github.io`). See README.md for layout and media.

- Style is deliberately 2010-plain: black background, monospace, underlined links, no JS, no frameworks,
  no animations, no icons. Do not "improve" the design unless asked.
- One shared `style.css`; every project page uses the same skeleton as the others.
- Copy is short, factual, first person. Numbers over adjectives.
- Oblivion Labs and Kurkumama: describe only, never link code or name clients.
- Raw .MOV footage is gitignored; commit compressed .mp4 (<15 MB) and resized images only.
